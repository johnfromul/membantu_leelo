# Changelog

## 1.0.0

Initial release.

- On/off control via switch entity
- Speed control (1–10) via number entity
- Timer interval selection (15/30/45/60 min, Unlimited) via select entity
- Remaining-time countdown via sensor entity
- Persistent speed and timer across restarts
- Automatic reconnect with periodic connection check
- Full BLE protocol reverse-engineered from the official app
